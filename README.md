# TurboVLA + EOVSAM

This repository contains the 2027 working version used for TurboVLA with EOVSAM.

- `EOVSAM/`: EOVSAM segmentation code and assets.
- `TurboVLA/`: TurboVLA model, training, evaluation, and integration code.
- `dependencies/detectron2/`: source dependency needed by EOVSAM.

Large or generated machine-local files are intentionally excluded: training outputs, checkpoints and model weights, Hugging Face and Torch caches, review/audit artifacts, build products, wheels, Python caches, and Git metadata.
